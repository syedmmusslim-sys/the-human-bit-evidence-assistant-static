Concierge pilot package

Scope

One close cycle, 1–3 clients, synthetic/redacted or separately governed data, one named CAS lead, one reviewer, one staff operator.

Timeline

Day 0 setup; days 1–10 run the close-readiness workflow; day 11 manager handoff review; day 12 scorecard and go/no-go.

Measured outcomes

Days to close-ready, chase touches, reviewer interruptions, duplicate re-asks, wrong evidence caught before manager review, and handoff acceptance.

Exit criteria

Stop if the data boundary cannot be maintained, staff cannot identify a recurring close blocker, or the manager says the handoff does not reduce review effort.

Roles to name

Named sponsor, named reviewer, and staff operator, agreed before day 0.

Data boundary

Synthetic/redacted or separately governed data only; no real client documents through the static kit.
