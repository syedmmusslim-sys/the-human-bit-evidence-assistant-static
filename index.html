What you can test

  • Staff intake starts items as waiting-review / problem / missing.
  • Reviewer accept/reject changes packet and blocker state immediately.

Why this is different from a prompt

A generic AI can draft copy from clean inputs. This sandbox shows enforced role gates, durable event IDs, packet inclusion rules, and a visible audit trail.

Measured pilot promise

Sample-only panel tracks duplicate re-asks, reviewer rework, time-to-handoff, and manager confidence. It is labelled hypothesis until a governed pilot measures real baselines.
